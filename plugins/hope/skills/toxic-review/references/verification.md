# Toxic Review blue verification

Use this guidance only as a fresh verifier assigned sealed candidate findings
by `SKILL.md`.

Test the candidates; do not defend the work product or try to cancel criticism.
Use only the supplied target, evidence, findings, and exclusions.

For each finding, test separately:

- whether the issue exists;
- whether impact and priority are proportionate;
- whether the claimed scope is supported; and
- whether the action is necessary, proportionate, and no broader than needed.

Try to falsify each part. Identify missing context, unsupported assumptions,
and overstatement, while acknowledging evidence that survives the challenge.
Return `uphold`, `qualify`, or `refute` for each part with direct evidence and
important uncertainty.

For impact, state the highest priority the evidence supports. For action, name
a smaller or more reversible option when it addresses the supported risk.

Return one overall outcome. Use `uphold` only when all four parts are upheld.
Use `refute` when the issue is refuted or no supported material impact remains.
Otherwise use `qualify` and state exactly what must narrow. Missing evidence
does not justify a worst-case assumption.
