# Align design directions

Use this guidance when a material visual branch benefits from reaction evidence
and the project or person has yet to supply an authoritative direction. The
mockups serve the Align conversation; implementation owns component structure,
frontend architecture, and tools.

## Decide whether a visual probe contributes value

Use a visual probe when a new screen, component, layout, or style choice could
materially change the intended experience and an image would help the person
decide. Existing mockups, design systems, and settled visual authorities take
priority. A small correction, behavior-only change, or settled accessibility
fix usually keeps the visual branch closed.

## Ground the probe

Inspect the project's current screens, design rules, components, and brand
assets first. Add outside references when project evidence leaves a material
direction open and a research capability is available.

When outside grounding is unavailable, name the missing evidence and recommend
one path: request a reference, continue from project evidence, or exclude the
new visual direction from this task. Describe every source according to the
evidence actually inspected.

Use outside work as inspiration; preserve its influence without reproducing
another product's distinctive visual design. Record each reference that
materially influenced an option and explain the influence in Hope's own design
language.

## Create and compare

Use a suitable available capability to make two readable, meaningfully
different image mockups. A third belongs when it contributes another material
direction. Keep this temporary exploration outside product files.

Show every option in one response when the host supports images. For each
option, state its main idea, strengths, trade-offs, and material references.
Mark the recommendation as an AI proposal and explain why it best fits the
known goal and constraints.

Keep each option summary to one brief main idea. Give strengths and trade-offs
the same comparison axes. Ask the person to select an option or explicitly
delegate the choice, then feed the result into the decision tree and recompute the
frontier.

## Handle an unavailable probe

When the capability is unavailable or presentation fails, explain the missing
evidence. Offer the person a grounded choice among an existing
visual authority, delegation to the AI, or exclusion of the new direction.
Preserve the resulting design decision.

## Preserve the selection

When confirmed understanding needs an artifact, review the conversation
evidence for every direction shown, the recommendation, and the selected
option. In `designDirections`, include each direction's local image path,
description, and material references, along with the recommendation and
selection.

Use absolute paths to ordinary non-interlaced PNG files that meet the limits in
`artifact.md`. For every material outside reference, record a short explanation
of its influence. After publication, inspect the artifact and verify that every
shown direction, recommendation, and selection matches the conversation.
