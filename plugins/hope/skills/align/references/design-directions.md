# Align design directions

Use comparison images when an unresolved visual choice could materially
change the experience. Existing mockups, design systems, and explicit decisions
take priority. Routine corrections usually need no new visual exploration.

## Ground and compare options

Inspect current screens, design rules, components, and brand assets. Use outside
references only when they help resolve a missing direction; state what was
actually inspected and preserve material influences without copying a product's
distinctive design. Continue from sufficient project evidence when outside
sources are unavailable.

Create two readable, meaningfully different image mockups; add a third only for
another material direction. Keep temporary exploration outside product files.
Show all options together when the host supports images. Give each a brief main
idea, strengths and trade-offs on the same axes, and material references.
Recommend the best fit as an AI proposal.

Use any existing delegation to choose, or ask the person to select or delegate.
Feed the result back into the shared understanding. If image creation or
presentation is unavailable and the choice still matters, explain the evidence
gap and offer an existing visual authority, AI delegation, or exclusion.

## Preserve the selection

When an artifact is needed, include every shown direction, recommendation, and
selection in `designDirections`, with local image paths, descriptions, and
material references. Explain each outside reference's influence.

Use absolute paths to ordinary non-interlaced PNG files within the limits in
`artifact.md`. After publication, inspect that the options and selection match
the conversation. Implementation owns component structure and frontend tools.
