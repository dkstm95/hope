# Plain writing standard

Make the meaning easy to see.

Prefer a direct sentence over one that sounds formal, clever, or impressive.

## Principles

1. Avoid stale metaphors, similes, idioms, and stock phrases.
2. Prefer a short, familiar word when it carries the same meaning.
3. Remove every word that does not add meaning.
4. Prefer active voice when it makes the actor and action clearer.
5. Replace jargon, unfamiliar borrowed phrases, and technical terms with
   everyday language when possible. Explain a necessary term when it first
   appears.
6. Break any rule when following it would make the writing inaccurate, unclear,
   unnatural, or needlessly harsh.

These principles adapt George Orwell's six rules in
[Politics and the English Language](https://www.orwellfoundation.com/the-orwell-foundation/orwell/essays-and-other-works/politics-and-the-english-language/).

## Structure

- Lead with the conclusion, decision, or requested result.
- Let the current purpose, reader, and next action determine what belongs.
- Keep one main idea in each sentence.
- Split a sentence that is hard to understand in one pass.
- Give each paragraph one clear job.
- Keep related sentences together when splitting them would harm meaning, flow,
  or voice.
- In Markdown and plain text, separate prose paragraphs with one blank line.
- Use the target format's native paragraph structure.
- Use a heading when it helps the reader find or understand a section.
- Use a list for a real set, choice, sequence, or comparison.
- Consolidate repeated framing only when each copy adds no distinct meaning or
  voice and the remaining text still works on its own.
- Use an established semantic structure for a prerequisite, caveat, or next
  action the reader must notice.

## Boundaries

- Preserve meaning, facts, uncertainty, citations, numbers, and voice.
- Do not silently narrow, expand, or resolve the person's request.
- Keep exact code, commands, identifiers, interface text, and quotations exact.
- Keep a technical term when it is more precise than an everyday substitute.
- Write each language as original prose rather than copying another language's
  word order or idioms.
- Do not delete, demote, or reorder a material claim without authority.
- Leave visible spacing, typography, and styling to the renderer.
- Treat sentence length as a signal, not a fixed limit.
- Follow a stricter project rule when it serves a clear local need.

## Final check

Before returning the text, ask:

- Is the main point visible early?
- Does each sentence carry one main idea?
- Does each paragraph have one clear job?
- Can a familiar word replace a harder one?
- Can any word or sentence disappear without losing meaning?
- Is the actor hidden where naming it would help?
- Would a heading or list make real structure clearer?
- Did the revision change a fact, certainty level, citation, or intended tone?
- Does the result sound natural when read once?
- Does any phrase sound translated even though each word is correct?
