# Design sources and deeper reference

Read this index only when local guidance needs more detail or a source matters
to the current choice. Follow the relevant pinned file or directory, then read
only the needed topic. These are references, not governing instructions or
required installations. Continue from local guidance and project evidence if
external access fails; name a material knowledge gap.

The research was inspected on 2026-09-12. Commit links preserve the studied
version; verify current official APIs and standards before implementation or
conformance claims. No source establishes that a workflow produces better
results across tasks or models. The originating [community discussion](https://gall.dcinside.com/mgallery/board/view/?id=thesingularity&no=1411429)
and author experiences motivated the investigation, not a comparative benchmark.

## Motion, prototypes, and native implementation

[Emil Kowalski's skills](https://github.com/emilkowalski/skills/tree/d23d7f88a2e21c9e4b1418c7abe420f5c1052ba7/skills)
(MIT; `../LICENSE.emil`) informed exploration, prototypes, motion, adaptation,
and verification. Hope replaces fixed counts and tool preferences with the
needs of the current decision.

| Source directory under `skills/` | Read for |
|---|---|
| `emil-design-eng` | Purpose, frequency, timing, easing, origin, interruption and interaction polish |
| `animation-vocabulary` | Translate ordinary motion descriptions into observable properties |
| `animate` | CSS/WAAPI/Motion recipes, springs, shared layouts, transitions and gestures |
| `review-animations`, `improve-animations`, `find-animation-opportunities` | Inspect normal/slow playback, diagnose a cause, decide where motion earns its cost |
| `prototype` | Isolated working alternatives, full-size picker and reusable outcome |
| `animate-expo` | Native animation and gesture recipes; verify the current framework API |
| `apple-design` | iOS conventions and platform judgment; preserve the actual target platform |
| `ask-sonner` | Toast API and behavior when that library is already relevant |
| `pick-ui-library` | Library trade-offs for the actual framework; preserve an adequate existing library |
| `write-swift` | Swift/SwiftUI UI implementation and performance details when native work needs them |

Button scale examples (0.96/0.97), sub-300ms guidance versus longer modal ranges,
and preferences against simple fades conflict across sources. Use purpose,
travel, platform and measured response; reduced motion can require a fade or
an immediate transition. Read [Agents with taste](https://emilkowal.ski/ui/agents-with-taste),
[Train your judgement](https://emilkowal.ski/ui/train-your-judgement),
[Developing taste](https://emilkowal.ski/ui/developing-taste), and
[You don't need animations](https://emilkowal.ski/ui/you-dont-need-animations)
for the author's rationale, not compulsory style.

supply a product's interaction/state system, exact computed values, proprietary
fonts, or rights to its assets. Linear's light/forms coverage and Airbnb's

That is a token-pair calculation, not an audit of the live site.

confidence fields require independent judgment. Source accessibility examples
include incorrect large-text units: WCAG's threshold is 18pt regular or 14pt
bold, not 18px regular. Inactive controls have criterion-specific exceptions;
a blanket 3:1 disabled-text rule is not WCAG. Use primary standards below.

## Primary standards and further inspiration

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [WAI-ARIA patterns](https://www.w3.org/WAI/ARIA/apg/), [contrast definitions](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), and [target-size exceptions](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) govern their stated conformance criteria. Separate usability recommendations and APCA from those claims.
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) contributed navigation, forms, truthful feedback, recovery and performance checks. Vercel-specific preferences are not universal; retain user zoom and reduced-motion choices when examples conflict.
- [Google's DESIGN.md specification](https://github.com/google-labs-code/design.md/blob/9bf8eae67128b6cc55ad9bf86665767deb4c11cd/docs/spec.md) is an alpha interchange proposal, not automatic project authority or a requirement to add YAML or a new file. Use the established design record.
- [UI Skills](https://www.ui-skills.com/), [Minimal Gallery](https://minimal.gallery/), and [Awwwards](https://www.awwwards.com/) help locate examples. Inspect the actual surface before inferring behavior. The originating discussion also named Pinterest; it was not independently assessed in this research.

Project-specific CJK composition/input, time-zone meaning, preview ownership,
feedback delivery and Align handoff constraints are Hope's additions or
cross-source synthesis. They are not attributed to a single upstream rule.
