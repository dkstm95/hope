# Hope brand assets

These 1024 × 1024 lossless WebP files are the retained masters for the
Protected Light identity:

- `hope-protected-light-app.webp`: app icon with a dark rounded-square field
- `hope-protected-light-symbol.webp`: transparent symbol with a filled light core

The WebP masters preserve visible pixels and alpha from the final PNG exports.
Fully transparent pixels may not preserve their hidden RGB values.

Smaller PNG derivatives used by the README and plugin are stored under
`plugins/hope`.
