    승인 화면을 Align의 독립 설계 기준으로 확정

    변경 내용 보기
    요약
    Align 의도 문서 산출물

    Align이 끝나면 구현 전에 합의한 의도를 독립 실행형 HTML로 남기고, 이후 구현이 현재 합의를 계약처럼 다시 읽어 따르게 한다.

    문제
    일회성 인터뷰로 끝난 Align은 구현 의도가 사라져 여러 구현 시도와 후속 세션에서 의도 부채가 쌓인다.
    성공
    • 완료된 Align은 프로젝트 안에 하나의 HTML 문서를 자동 생성한다.
    • 같은 의도의 중요한 변경은 새 파일이 아니라 같은 문서의 리비전으로 남는다.
    • 구현을 시작하기 전에 현재 리비전을 다시 읽어 구현 계약으로 사용한다.
    • 승인된 화면의 정보 구조, 밀도, 반응형 구성, 라이트·다크 표현을 Align 자체 설계로 재현한다.
    • 현재 Diff 렌더러와 테마 토큰은 변경하지 않는다.
    경계
    Align 문서는 구현 전 의도와 합의만 보존한다. 이번 작업은 Align의 독립 산출물과 시각 기준까지만 구현하며 Diff 리팩터링은 별도 작업으로 남긴다.
    포함 범위
    • Align 완료 시 HTML 생성과 같은 의도 문서의 안전한 리비전 갱신
    • 프로젝트 문서 관례를 따르는 저장 위치와 기본 docs/alignments 경로
    • 승인된 화면을 기준으로 한 콤팩트한 반응형 레이아웃
    • Align이 독립 소유하는 시각 기준 이미지, 토큰, 라이트·다크 전환
    • 구현 전 현재 리비전 재확인과 저장소 포함 권고
    제외 범위
    • Diff 산출물 링크와 의도 대비 구현 비교
    • Diff 렌더러, Diff 테마 토큰, Diff 화면 리팩터링
    • 삭제된 Align 구현 이력을 새 화면의 설계 근거로 사용
    • Align과 Diff가 함께 쓰는 시각 토큰 또는 컴포넌트 계층
    • git add, 커밋, 푸시와 전역 최신 Align 자동 탐색
    • 구현 진행률, 완료 체크, 변경 파일과 테스트 상태 표시
    합의된 동작
    • 의도 합의 — 중요한 질문과 선택을 마무리한다.
    • 문서 생성 또는 개정 — 한 의도의 현재 합의와 이력을 같은 HTML에 보존한다.
    • 구현 승인 — 사용자가 명시적으로 구현 시작을 승인한다.
    • 현재 합의 재확인 — HTML의 현재 리비전을 다시 읽고 구현을 시작한다.
    합의된 결정
    • 승인 화면을 구현 명세로 사용 — 합의된 시안의 정보 구조와 시각 위계를 방향성이 아니라 구현 기준으로 보존한다.
    • Align이 시각 기준을 독립 소유 — Align 전용 기준 이미지와 토큰을 두어 Diff나 삭제된 구현의 제약 없이 화면을 재현한다.
    • 한 의도에 한 HTML — 구현 횟수만큼 파일이 늘어나는 문제를 막고 의도 이력을 한곳에 보존한다.
    • 현재 합의를 우선 표시 — 구현자는 과거 이력보다 지금 지켜야 할 기준을 먼저 확인해야 한다.
    • Align 자체 라이트·다크 전환 — 시스템 테마를 기본으로 사용하고 열린 문서에서만 Align의 두 테마를 전환한다.
    • Hope 소유권 검증 후에만 개정 — 알 수 없거나 사람이 편집한 파일을 자동으로 덮어쓰지 않는다.

Align 의도 문서 산출물

Align이 끝나면 구현 전에 합의한 의도를 독립 실행형 HTML로 남기고, 이후 구현이 현재 합의를 계약처럼 다시 읽어 따르게 한다.

결정과 구현 선택

합의된 결정

  1. 01

    승인 화면을 구현 명세로 사용

    합의된 시안의 정보 구조와 시각 위계를 방향성이 아니라 구현 기준으로 보존한다.

  2. 02

    Align이 시각 기준을 독립 소유

    Align 전용 기준 이미지와 토큰을 두어 Diff나 삭제된 구현의 제약 없이 화면을 재현한다.

  3. 03

    상단 간격을 두 단계로 제한

    상단 주요 항목은 같은 간격을 사용하고 테마와 탐색 같은 액션 안에서만 더 작은 간격을 사용한다.

  4. 04

    결과 행 기준 연결선

    동작 분기 좌표를 결과 행에서 계산해 문장 길이가 달라도 선 끝과 결과 표시가 맞게 한다.

  5. 05

    결정 번호와 쉬운 제목

    결정을 빠르게 구분하고 어려운 표현 대신 결정과 구현 선택이라는 제목을 사용한다.

  6. 06

    의도 이력은 보조 탐색에만 표시

    본문 하단의 중복을 없애고 데스크톱 레일과 좁은 화면의 우측 패널에서 과거 합의를 펼쳐 본다.

  7. 07

    한 의도에 한 HTML

    구현 횟수만큼 파일이 늘어나는 문제를 막고 의도 이력을 한곳에 보존한다.

  8. 08

    Hope 소유권 검증 후에만 개정

    알 수 없거나 사람이 편집한 파일을 자동으로 덮어쓰지 않는다.

    Align 의도 문서 산출물

    Align이 끝나면 구현 전에 합의한 의도를 독립 실행형 HTML로 남기고, 이후 구현이 현재 합의를 계약처럼 다시 읽어 따르게 한다.

    문제
    일회성 인터뷰로 끝난 Align은 구현 의도가 사라져 여러 구현 시도와 후속 세션에서 의도 부채가 쌓인다.
    성공
    • 완료된 Align은 프로젝트 안에 하나의 HTML 문서를 자동 생성한다.
    • 같은 의도의 중요한 변경은 새 파일이 아니라 같은 문서의 리비전으로 남는다.
    • 구현을 시작하기 전에 현재 리비전을 다시 읽어 구현 계약으로 사용한다.
