DIAGRAM · HANDOFF-01

How does my parcel reach the front door? 주문한 택배는 어떻게 문 앞까지 올까?

One parcel changes hands three times. Each handoff changes who is responsible and what moves next. 하나의 택배가 세 번 인계됩니다. 인계할 때마다 책임자와 다음에 전달되는 것이 달라집니다.

Fulfillment turns the order details into a labeled, packed parcel for the courier.

Scope: this simplified example covers one successful home delivery. Real deliveries may add sellers, regional hubs, subcontractors, lockers, or returns. It uses sample data. 범위: 이 단순화한 예시는 한 번의 정상적인 자택 배송을 다룹니다. 실제 배송에는 판매자, 지역 허브, 협력사, 보관함, 반품 과정이 더해질 수 있습니다. 샘플 데이터를 사용했습니다.
